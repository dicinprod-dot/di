GitHub token

Токен нужен, чтобы страница могла записывать в репозиторий. Он хранится только в этом браузере и уходит напрямую на api.github.com.
Создать: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Repository access: только dicinprod-dot/di. Permissions → Repository permissions → Contents: Read and write.
